Android 版本说明：
- Android 应用版本：1.0.14
- Android versionCode：10014
- Android 安装包：APK / AAB
- 我的片库集中查看手机和平板本地媒体与个人网盘作品的收藏、待看和合集，支持搜索、筛选和排序。
- 收藏、待看、合集和观看进度与作品身份关联；来源更名、重新分组或恢复备份时，在身份明确的情况下继续保留。
- 电影、动漫和电视剧分类复用已有媒体库资料，减少重复读取；无效或已删除的本地媒体不会继续出现在分类结果中。
- 更新或重新刮削 TMDB 资料时保留人工分类、题材标签和图片选择；资料导入失败时恢复原有内容。
- 启动时优先显示你选择的首页，首页出现后再显示更新说明。
- 继续支持本地媒体库、个人网盘、字幕、音轨、后台播放、画中画、MediaCodec 硬件解码和 Anime4K。

Windows 版本说明：
- Windows 应用版本：1.0.18
- Windows 安装器版本：1.0.18
- 我的片库集中管理本地与个人网盘作品的收藏、待看和合集，支持搜索、筛选和排序；来源变更或恢复备份后，在作品身份明确时继续关联记录。
- 电影、动漫和电视剧分类复用已有媒体库资料，大型片库按需检查旧索引，减少重复读取和切页等待。
- 启动时优先打开你选择的首页，首页显示后再呈现更新说明；快速切换分类时打开最后选中的页面。
- 媒体资料更新与导入保留人工分类、标签和图片选择，写入失败时恢复原有资料。
- TMDB 题材标签继续采用刮削结果；主分类在信息不足或冲突时可确认，重新刮削不会覆盖人工设置。
- 网盘季度支持重新刮削本季；只更新当前季资料并保留手动图片选择。
- Windows 安装时可以在向导中选择安装目录；应用数据目录和缓存目录使用看影音专属位置。
- 本次更新不会修改或删除本地及网盘原始视频、字幕或其他文件。
