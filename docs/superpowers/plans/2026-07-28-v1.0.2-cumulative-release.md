# 看影音 1.0.2 累积正式版实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将当前 `2.1.65` 代码统一为 `1.0.2` 正式版，生成并验证 Windows 下载包，推送 `main`，创建并发布 GitHub `v1.0.2` Release。

**Architecture:** 本次不改变已完成的媒体库、播放器或网盘业务实现，只调整正式版元数据、用户文案和版本测试。发布按“目标测试 → 全量测试与分析 → Windows Release 与签名包 → Git 提交推送 → GitHub 草稿 Release 附件校验 → 发布 Latest”顺序执行，任何门禁失败都停止后续外部发布动作。

**Tech Stack:** Flutter 3.41.9、Dart、Flutter Test、PowerShell、MSIX、Git、GitHub CLI/REST API。

```markdown
## 1.0.2+10002

MSIX 版本：1.0.2.0

### 更新弹窗文案

标题：看影音 1.0.2 正式版

- 夸克、百度和 OpenList 的多选媒体目录支持一键清除，再重新选择需要的目录；清除选择不会访问或删除网盘文件。
- 剧场版、OVA 和特别电影可作为独立电影识别并进行 TMDB 刮削，同一电影的不同清晰度、字幕或音轨版本会合并展示，同时保留全部可播放版本。
- 修复方括号发布名、中文剧名紧接连续集号、混合目录、导演剪辑版以及 `10th`、`10bit` 等数字引起的识别错误；升级后可自动重建旧错误索引。
- 单一第一季作品只显示作品名，不再追加多余的“第 1 季”；多季或非第一季作品继续显示正确季号。
- 网盘海报卡支持隐藏单个视频版本，隐藏记录在重启和重新扫描后保留，并可逐个或全部恢复；隐藏只影响海报墙，不会删除网盘文件或播放信息。
- 改进退出时的播放器资源、网盘分段缓存和诊断日志清理；字幕目录改为异步读取，百度请求补齐连接超时和明确失败反馈。
- 修复只有 TrueHD 音轨的视频能够识别音轨却没有声音，以及蓝光 PGS 内嵌字幕能够识别字幕轨却无法显示的问题。
- 保留 Windows 硬件解码、4K 零拷贝渲染和 Anime4K 行为；没有 TMDB Key、断网或 TMDB 暂时不可用时，本地与网盘媒体库及播放器仍可使用。本次更新不会修改、删除或转码原始视频和字幕文件。
```

保留已有 `1.0.1` 和 `2.1.56–2.1.65` 历史，不删除测试版区块。

```powershell
$env:GIT_CONFIG_GLOBAL = 'NUL'
$gitNet = @(
  '-c', 'http.proxy=http://127.0.0.1:7897',
  '-c', 'credential.helper=',
  '-c', 'credential.helper=!gh auth git-credential'
)
$repoUrl = 'https://github.com/ddddd-ren/KanYingYin.git'
git tag -a v1.0.2 -m '看影音 v1.0.2 正式版'
& git @gitNet push $repoUrl HEAD:refs/heads/main
& git @gitNet push $repoUrl refs/tags/v1.0.2
& git @gitNet fetch $repoUrl main:refs/remotes/origin/main
```

Expected: 远端 `main` 和 `v1.0.2^{}` 均指向发布提交。
