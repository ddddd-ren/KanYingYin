- [ ] **Step 1: 在移除源码字面量前完成一次 DPAPI 迁移**

使用 PowerShell 从当前四个静态字段读取值，只将 `SecureString` 导出到当前用户签名目录；命令不得输出字段值：

```powershell
$source = Get-Content 'lib/services/cloud/xunlei/xunlei_request_policy.dart' -Raw -Encoding UTF8
$fields = @{
  'clientId' = 'xunlei-client-id.clixml'
  'clientSecret' = 'xunlei-client-secret.clixml'
  'webClientId' = 'xunlei-web-client-id.clixml'
  'appKey' = 'xunlei-app-key.clixml'
}
foreach ($entry in $fields.GetEnumerator()) {
  $match = [regex]::Match($source, "static const String $($entry.Key) = '([^']+)';")
  if (-not $match.Success) { throw "缺少字段 $($entry.Key)" }
  ConvertTo-SecureString $match.Groups[1].Value -AsPlainText -Force |
    Export-Clixml (Join-Path "$env:USERPROFILE\.kanyingyin\signing" $entry.Value)
}
```

- [ ] **Step 3: 实现最小强类型配置**

```dart
final class XunleiClientConfiguration {
  const XunleiClientConfiguration({
    this.clientId = const String.fromEnvironment('KANYINGYIN_XUNLEI_CLIENT_ID'),
    this.clientSecret = const String.fromEnvironment('KANYINGYIN_XUNLEI_CLIENT_SECRET'),
    this.webClientId = const String.fromEnvironment('KANYINGYIN_XUNLEI_WEB_CLIENT_ID'),
    this.appKey = const String.fromEnvironment('KANYINGYIN_XUNLEI_APP_KEY'),
  });

  final String clientId;
  final String clientSecret;
  final String webClientId;
  final String appKey;

  bool get isConfigured =>
      clientId.trim().isNotEmpty &&
      clientSecret.trim().isNotEmpty &&
      webClientId.trim().isNotEmpty &&
      appKey.trim().isNotEmpty;
}
```

`XunleiRequestPolicy` 接收该配置并将签名、请求头和 API 参数改为实例访问；配置缺失时在网络调用前抛出稳定的未配置异常，编辑页转成普通用户提示。
