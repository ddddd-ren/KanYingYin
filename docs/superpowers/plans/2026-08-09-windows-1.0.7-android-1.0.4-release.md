# 看影音 Windows 1.0.7 与 Android 1.0.4 正式版实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将当前测试版整理为 Windows 1.0.7 和 Android mobile 1.0.4 正式版，并只向 GitHub 发布 Windows EXE、Android APK、Android AAB。

**Architecture:** Windows 版本继续由 `pubspec.yaml` 和 `AppVersion` 驱动；Android 正式版使用独立的 `versionName 1.0.4` 与 `versionCode 10004`，由 Gradle 和 PowerShell 构建脚本共同校验。用户文案按平台筛选共享更新，Android TV 发布流程保持无限期停用。

**Tech Stack:** Flutter 3.41.9、Dart、Gradle Kotlin DSL、PowerShell、Inno Setup、Android SDK build-tools、Git、GitHub CLI。

---

## 文件职责

- `pubspec.yaml`：Windows 正式版和历史 MSIX 兼容版本。
- `lib/core/app_version.dart`：Windows 应用显示版本。
- `android/app/build.gradle.kts`：Android mobile 正式版版本和签名配置。
- `tool/android/build_signed_release.ps1`：只构建并验证指定 flavor，本次仅调用 `mobile`。
- `UPDATE_DIALOG_COPY.md`：Windows 与 Android 手机版用户弹窗定稿。
- `RELEASE_NOTES.md`：本次正式版下载说明和历史更新记录。
- `lib/utils/version_history.dart`：应用内平台化版本历史。
- `README.md`：当前版本与正式版下载说明。
- `test/version_consistency_test.dart`：Windows 1.0.7 与 Android 1.0.4 双版本一致性。
- `test/release_config_contract_test.dart`：当前正式版发布契约和 TV 禁发约束。
- `test/android_release_packaging_test.dart`：Android mobile 版本解析、签名和构建脚本契约。
- `test/version_history_current_test.dart`：正式版平台文案内容和 TV 文案隔离。
