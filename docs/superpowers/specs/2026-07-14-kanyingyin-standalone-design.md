# 看影音独立项目设计

## 目标

从 `D:\KanYingYin-src` 完整复制并删减出新的 Windows Flutter 项目 `D:\KanYingYin`。新应用显示名称为“看影音”，Dart 包名为 `kanyingyin`，Windows 包标识为 `com.kanyingyin.player`。

新项目完整保留“就看”现有本地媒体库、本地播放器、视觉样式和动画逻辑，删除在线播放、插件规则和 WebView 等能力，并增加面向本地媒体库的 TMDB 元数据刮削。

首版只支持 Windows，并以可安装的 MSIX 作为交付物。

## 实施策略

采用“完整复制后删减”方案：

1. 完整复制当前“就看”项目，先保证新项目可以独立构建。
2. 修改应用名称、Dart 包名、Windows 包标识、数据目录和安装包配置。
3. 保留本地媒体库与播放器代码，逐步移除在线模块和相关依赖。
4. 将本地播放从在线番剧兼容模型中解耦，建立强类型本地播放模型。
5. 增加 TMDB 刮削、缓存、手动匹配和内容锁定能力。
6. 完成测试、Windows Release 构建和 MSIX 验证。

此方案优先保证播放器 UI、交互和动画与当前“就看”一致，避免从空项目迁移时遗漏行为。

## 保留范围

完整保留以下能力：

- 本地媒体源、目录浏览、扫描和索引。
- 系列分组、剧集识别、封面抓取与自定义封面。
- 手动修改剧名、本地搜索和媒体库展示。
- 本地播放列表、自动连播和观看历史。
- 播放器全部 UI、键鼠交互、快捷键和动画逻辑。
- 字幕自动匹配、导入、选择和样式设置。
- 硬件解码、倍速、画面比例、音量、亮度和音轨控制。
- Anime4K 超分辨率及现有着色器。
- 主题、日志、Windows 窗口管理和本地设置。
- 首次启动快捷方式确认弹窗、更新日志和 MSIX 打包流程。

## 删除范围

删除以下在线能力及其路由、设置项和依赖：

- 在线插件和规则引擎。
- WebView 及视频在线解析。
- 在线搜索、推荐、时间表和 Bangumi 网络功能。
- 在线评论、验证码、线路测速和在线代理功能。
- 在线资源下载、WebDAV 同步、同步播放和投屏。
- 仅服务于在线资源的页面、模型、服务和依赖。

删除后不得在导航或设置中保留无效入口。

## 核心架构

本地扫描链路沿用当前实现，但不再通过 `BangumiItem` 和 `Road` 模拟在线番剧：

```text
本地目录
-> 视频文件扫描
-> 文件名与季集解析
-> 系列分组
-> TMDB 自动匹配
-> 元数据与图片缓存
-> 本地媒体库展示
-> 本地播放会话
-> media_kit 播放器
```

本地播放使用以下领域对象：

- `LocalMediaSeries`：一个电影或系列的媒体库聚合对象。
- `LocalEpisode`：本地单集，保存原始文件路径和剧集信息。
- `LocalPlaybackSession`：当前播放列表、当前集、字幕和恢复进度。

播放器调用关系由：

```text
BangumiItem + Road + VideoPageController
-> PlayerController
```

调整为：

```text
LocalMediaSeries + LocalEpisode + LocalPlaybackSession
-> PlayerController
```

`PlayerController` 保留本地播放状态和控制行为，移除在线测速、HTTP 请求头、代理、同步播放和投屏逻辑。

## TMDB 刮削

用户在设置页填写自己的 TMDB API Key。应用不内置公共密钥。

刮削流程：

```text
扫描本地视频
-> 解析剧名、年份、季集编号
-> 搜索 TMDB
-> 自动选择高置信度结果
-> 下载元数据和图片
-> 写入本地索引与缓存
-> 低置信度结果等待用户确认
```

刮削内容包括：

- 中文标题和原始标题。
- 简介、年份和评分。
- 海报和背景图。
- 电影、电视剧及季集信息。
- TMDB ID、媒体类型、匹配状态和最后刮削时间。

刮削规则：

- 优先请求简体中文，缺失字段回退英文。
- 高置信度结果自动匹配。
- 同名、多结果或低置信度时进入待确认列表。
- 支持单项重新刮削、批量刮削和手动选择匹配结果。
- 用户修改的剧名、封面和简介默认锁定，批量刮削不得覆盖。
- TMDB 不可用、无密钥或断网时跳过刮削，不阻塞本地扫描和播放。
- 删除媒体源只删除应用索引和相关缓存，不删除用户视频文件。

## 播放器与动画

播放器文件、控件层级和动画实现以当前“就看”为迁移基准，不重新设计播放器 UI。

完整保留：

- 控制层出现、隐藏和自动收起动画。
- 播放、暂停、缓冲和加载状态切换。
- 全屏进入退出、窗口尺寸变化和画中画逻辑。
- 进度拖动、快进快退、音量和亮度交互。
- 播放列表展开、收起和选集切换动画。
- 字幕选择、导入和字幕样式面板。
- 倍速、画面比例、硬件解码和音轨控制。
- Anime4K 超分辨率与着色器设置。
- 自动连播、播放结束和下一集切换。
- 禁用播放器动画设置及现有动画时长和曲线。

观看进度以本地媒体 ID 保存。重新扫描或文件改名后，应尽量通过稳定文件标识关联原记录。

## 页面与导航

首版页面包括：

- 本地媒体库：保持当前“就看”本地页面布局、卡片样式、搜索、系列分组和动画。
- 系列详情：展示 TMDB 背景图、海报、简介、评分、季集列表和观看进度。
- 播放器：完整保留当前本地播放器 UI 和动画。
- 历史记录：只显示本地视频观看记录。
- 设置：播放器、字幕、超分、主题、本地目录、TMDB 和缓存设置。
- 日志：记录本地扫描、刮削和播放错误。
- 关于：显示“看影音”名称、版本和更新日志。

应用启动后直接进入本地媒体库。没有媒体源时显示选择本地视频文件夹的空状态，添加后立即扫描，并允许用户选择是否自动执行 TMDB 刮削。

导航、页面切换动画、窗口标题栏、主题颜色和响应式布局沿用当前实现。

Windows 支持从资源管理器通过“打开方式”播放单个视频。临时打开的视频不强制加入媒体库。

## 本地存储

继续使用 Hive，但“看影音”使用独立数据目录，不读取或覆盖“就看”的设置、历史和媒体索引。

分别管理：

- 媒体源和媒体索引。
- 观看历史与播放进度。
- TMDB 元数据缓存。
- 海报和背景图缓存。
- 字幕和用户导入文件。
- 应用设置及内容锁定状态。

设置页提供缓存占用查看和清理功能。

## 异常处理

- 文件夹不可访问：保留媒体源并标记离线。
- 文件移动或删除：标记不可用，不立即删除观看历史。
- 扫描中断：保留上一次完整索引。
- TMDB 无密钥或断网：跳过刮削，本地媒体库和播放器继续可用。
- TMDB 匹配冲突：进入待确认列表。
- 图片下载失败：使用已有本地封面或统一占位图。
- 视频打开失败：提供重新尝试、打开文件位置和系统播放器打开操作。
- 播放器异常退出：通过定期保存播放进度减少记录丢失。

## 非目标

- Android、macOS 和 Linux 发布。
- 在线视频搜索、解析和播放。
- 插件规则系统和 WebView。

- 在线评论、弹幕、投屏和同步播放。
- 对 `D:\媒体库` WPF 项目的代码或界面复用。
