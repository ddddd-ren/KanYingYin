# 网盘多选目录一键清除设计

## 背景与目标

夸克、百度和 OpenList 的媒体来源都复用统一网盘目录选择页，并允许一次选择多个媒体目录。已选目录较多时，用户目前只能逐项取消勾选。

本次测试版在多选目录页面增加“一键清除已选”能力，让用户一次取消页面中的全部临时选择。该操作不访问或修改网盘文件，不清除媒体索引、TMDB 刮削信息或缓存。

## 功能范围

- 适用于夸克、百度和 OpenList 的多选媒体目录页面。
- 不适用于夸克默认转存目录等单选页面。
- 只清空当前目录选择页面内的临时选择。
- 用户点击“确定”后，空目录列表才返回来源编辑页；离开页面则放弃本次变化。

## 交互设计

在统一目录选择页的顶部操作栏增加“清除已选”按钮：

- 多选模式始终显示按钮。
- 没有已选目录时按钮禁用。
- 存在已选目录时，点击按钮立即取消全部勾选，不弹确认框。
- 清除后已选数量显示为 0，“确定”按钮同步禁用。
- 单选模式不显示该按钮，保持现有交互不变。

不弹确认框的原因是该操作仅改变页面内的临时状态，用户退出页面即可放弃，尚未产生持久化修改。

## 实现边界

改动集中在 `CloudDirectoryPickerPage`：

- 增加清空内部 `_selected` 集合的页面状态操作。
- 根据 `singleSelection` 决定是否构建“清除已选”按钮。
- 根据 `_selected.isEmpty` 控制按钮和“确定”按钮状态。

夸克、百度和 OpenList 已复用该页面，无需分别实现清除逻辑，也不修改来源仓库、凭据、扫描、索引、TMDB 或缓存服务。

## 数据流与错误处理

1. 页面使用 `initialSelection` 初始化临时选择集合。
2. 用户点击“清除已选”，页面仅清空临时集合并刷新界面。
3. 用户重新选择目录后可继续提交。
4. 用户点击“确定”时，继续使用现有 `resultBuilder` 返回排序后的选择结果。

清除操作不执行异步请求，因此没有网络错误或部分失败状态。目录加载和地址跳转仍沿用现有错误处理。

## 测试与验收

按测试驱动方式补充统一目录选择页组件测试：

- 多选页面存在“清除已选”按钮。
- 初始选择为空时按钮禁用。
- 存在初始选择时按钮可用，点击后所有勾选取消、数量归零且“确定”禁用。
- 清除后重新勾选目录可恢复正常提交。
- 单选页面不显示“清除已选”按钮。
- 夸克、百度和 OpenList 继续复用统一页面，不改变现有选择结果类型。
