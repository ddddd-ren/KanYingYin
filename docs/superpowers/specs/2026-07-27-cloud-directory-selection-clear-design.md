# 网盘媒体根目录一键清除设计

## 背景与目标

夸克、百度和 OpenList 来源编辑页会展示当前配置的多个媒体根目录。目录较多时，用户目前只能重新进入目录选择页逐项取消，无法从来源编辑页直接清空。

本次迭代在来源编辑页的“媒体根目录”区域、紧邻“选择目录”操作增加“清除”按钮。点击后只清空尚未保存的表单目录列表，不访问或删除网盘文件，也不清理看影音中的索引、TMDB 刮削信息或缓存。

## 功能范围

- 覆盖夸克、百度和 OpenList 来源编辑页的多选媒体根目录。
- 清除按钮显示在目录摘要和“选择目录”按钮所在区域。
- 不影响夸克“默认转存目录”等单选配置。
- 移除 2.1.56 中误加在统一目录选择弹窗顶部的“清除已选”。
- 作为 `2.1.57+20157`、MSIX `2.1.57.0` 测试版交付。

## 交互设计

- 媒体根目录非空且页面空闲时，“清除”按钮可用。
- 目录为空或页面正在保存、浏览、授权、加载凭据、更新媒体库时，按钮禁用。
- 点击后立即清空页面内的根目录集合，摘要显示“尚未选择”。
- 不弹确认框；在用户保存来源前，清除只属于可放弃的表单变化。
- 清除按钮不要求当前网盘授权有效，避免旧授权失效时无法先清理旧目录。
- 保存时继续遵循各来源现有校验和刷新行为，本次不改变来源持久化规则。

## 实现边界

- `QuarkSourceEditorPage`：为可复用 `_DirectorySection` 增加可选清除动作，仅媒体根目录实例启用，默认转存目录不启用。
- `BaiduSourceEditorPage`：在媒体根目录行增加清除动作，清空 `_rootRefs`。
- `OpenListSourceEditorPage`：在扫描目录行增加清除动作，清空 `_rootPaths`，空列表显示“尚未选择”。
- `CloudDirectoryPickerPage`：移除 2.1.56 误加的清除按钮和状态方法，恢复为只负责选择目录。

## 数据与安全边界

清除动作只执行页面内 `setState`，不调用目录加载器、来源仓库、凭据存储、扫描器、索引仓库、TMDB 服务或缓存服务。只有用户后续点击来源编辑页“保存”时，才沿用现有保存流程处理表单结果。

## 测试与验收

- 先写组件测试，确认三种来源的已有目录可被一键清空并显示“尚未选择”。
- 验证目录为空时按钮禁用，页面忙碌时按钮禁用。
- 验证夸克默认转存目录未被清除，且单选配置没有清除入口。
- 验证统一目录选择弹窗不再显示“清除已选”。
- 运行三种来源编辑器回归测试、全量 `flutter test`、`flutter analyze` 和 Windows Release 构建。
- 生成签名 MSIX，核验包身份、清单版本、架构、签名和 SHA-256，并复制为桌面 `看影音-2.1.57.msix`。
