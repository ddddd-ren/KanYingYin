# 网盘海报墙隐藏视频设计

日期：2026-07-28
状态：待用户书面评审

## 目标

允许用户在网盘海报墙中隐藏不喜欢的具体视频版本。例如同一影片同时存在 A、B 两个版本时，可以只隐藏 B，A 继续显示和播放。

隐藏仅影响看影音中的网盘海报墙，不删除网盘文件，不删除媒体索引，不修改远程文件 ID、目录或播放地址。

## 交互设计

### 隐藏入口

在海报卡右上角的“资源操作”菜单底部增加“隐藏视频”，与现有“修改刮削名称”“TMDB 刮削”“重新匹配”“媒体详情”保持同一菜单层级。

- 卡片只有一个真实视频时：显示确认对话框，确认后隐藏该视频。
- 卡片包含多个剧集或版本时：显示视频选择对话框。每项展示应用内显示名、版本规格和远程路径，用户勾选一个或多个视频后点击“隐藏所选”。
- 没有勾选任何视频时，“隐藏所选”按钮不可用。
- 隐藏 B 后，A 和同作品的其他未隐藏视频继续留在原卡片中。
- 隐藏卡片内最后一个可见视频后，该卡片从海报墙消失。

### 恢复入口

在网盘页面顶部“更多网盘操作”中增加“管理已隐藏视频”。该入口管理当前选中的网盘来源。

- 列表展示已隐藏视频的文件名和远程路径。
- 支持逐个恢复。
- 支持“全部恢复”，操作前需要确认。
- 恢复后视频立即重新参与海报墙分组，无需重新扫描。
- 当前来源没有隐藏视频时，显示明确空状态。

如果当前来源的可见视频全部被隐藏，海报墙显示“视频已隐藏，可从更多网盘操作中恢复”，避免与扫描不到视频混淆。

## 数据与持久化

新增独立的海报墙隐藏记录存储，不把隐藏状态写入网盘媒体索引。每条记录保存：

- 网盘来源 ID；
- 远程文件 ID；
- 规范化远程路径；
- 用户可识别的文件名。

匹配时优先使用来源 ID 和远程文件 ID；旧来源或缺少稳定文件 ID 时回退到来源 ID 和规范化路径。独立存储带来以下行为：

- 应用重启后隐藏状态保留；
- 重新扫描或替换媒体索引后隐藏状态保留；
- 隐藏不会导致视频无法播放，也不会丢失字幕、TMDB 或发布规格信息；
- 移除网盘来源时同步清理该来源的隐藏记录，但不接触网盘文件。

损坏或字段不完整的记录会被忽略，不能阻止网盘媒体库加载。

## 组件边界与数据流

### 隐藏记录仓库

新增一个专门仓库负责读取、写入、按来源查询和清理隐藏记录。仓库写入采用“先生成新快照、写入成功后再更新控制器状态”的顺序，避免保存失败时界面错误地隐藏视频。

### 网盘资源控制器

`CloudResourcesController` 保留完整的扫描结果和媒体索引，只在生成海报墙集合前排除隐藏记录：

1. 加载当前来源的隐藏记录；
2. 对索引作品流和兼容的原始条目流应用同一过滤规则；
3. 将过滤后的条目交给现有分组器；
4. 隐藏或恢复成功后更新内存记录并通知界面重建。

控制器提供隐藏、逐个恢复、全部恢复以及查询当前来源隐藏列表的接口。播放请求仍只接收可见条目；底层索引不被修改。

### 海报墙与页面

`CloudResourcePosterWall` 只负责增加菜单动作回调。单视频确认、多视频选择、错误提示和恢复管理由 `CloudResourcesPage` 负责，持久化操作委托给控制器。

这种边界保持海报卡为纯展示组件，也让隐藏规则可以独立测试。

## 错误处理

- 隐藏记录保存失败：保持原海报墙不变，提示“隐藏设置保存失败，请重试”。
- 恢复保存失败：保持视频隐藏，提示“恢复失败，请重试”。
- 隐藏记录读取失败：不隐藏任何视频，继续显示网盘媒体库，并给出非阻断提示。
- 正在扫描时允许隐藏和恢复；扫描完成后重新应用同一隐藏记录。

## 测试与验收

采用测试驱动实现，至少覆盖：

1. 隐藏记录跨仓库实例持久化，损坏记录被安全忽略。
2. 同作品 A、B 两个版本中隐藏 B 后，集合仍保留 A，B 不参与播放列表。
3. 隐藏唯一视频后卡片消失，恢复后无需扫描即可重新出现。
4. 重新扫描替换索引后隐藏状态仍然生效。
5. 保存失败时控制器和界面状态不变并显示错误。
6. 资源操作菜单包含“隐藏视频”，多版本对话框可精确选择 B。
7. “管理已隐藏视频”可逐个和全部恢复。
8. 移除来源时清理该来源的隐藏记录，不影响其他来源。
9. 现有网盘播放、字幕、TMDB 刮削和媒体详情测试继续通过。

交付版本更新为下一个测试版，同时更新 `pubspec.yaml`、MSIX 版本、发布说明和版本历史。最终必须通过全量 `flutter test`、`flutter analyze`、Windows Release 构建、MSIX 签名与清单验证，并把安装包复制到桌面。

## 非目标

- 不修改或删除网盘文件。
- 不改变媒体识别大小规则。
- 不提供跨来源的批量隐藏。
- 不自动根据文件名、清晰度或编码隐藏版本。
- 本次不为本地媒体库增加同类功能。
