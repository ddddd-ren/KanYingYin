# 看影音 1.0.2 累积正式版发布设计

## 目标

将当前 `2.1.65` 代码作为看影音 `1.0.2` 正式版发布到 GitHub。同步更新应用版本、MSIX 版本、更新弹窗、发布说明、版本历史、README 和版本测试，完成 Windows Release、签名 MSIX、异机安装包、Git 推送和 GitHub Release 交付。

现有 `v1.0.1` Release 保留；新建 `v1.0.2` Release 并设为 Latest。

## 版本与发布渠道

- Dart/Flutter 版本：`1.0.2+10002`
- Windows MSIX 版本：`1.0.2.0`
- 应用内版本：`1.0.2`
- 发布类型：正式版
- Git 标签：`v1.0.2`
- GitHub Release：非草稿、非预发布、设为 Latest

本次版本更新开始时，Windows 已安装版本记录为 `2.1.65.0`。本次不自动卸载或安装应用，也不在用户弹窗、发布说明或 GitHub 描述中加入测试版降级安装提示。

## 面向用户的更新说明

`RELEASE_NOTES.md`、`UPDATE_DIALOG_COPY.md` 与 `lib/utils/version_history.dart` 使用同一组核心信息，标题统一为“看影音 1.0.2 正式版”。正文聚焦普通用户可感知的变化：

1. 夸克、百度和 OpenList 的多选媒体目录支持一键清除，再重新选择需要的目录；清除选择不会访问或删除网盘文件。
2. 剧场版、OVA 和特别电影可作为独立电影识别并进行 TMDB 刮削，同一电影的不同清晰度、字幕或音轨版本会合并展示，同时保留全部可播放版本。
3. 修复方括号发布名、中文剧名紧接连续集号、混合目录、导演剪辑版以及 `10th`、`10bit` 等数字引起的识别错误；升级后可自动重建旧错误索引。
4. 单一第一季作品只显示作品名，不再追加多余的“第 1 季”；多季或非第一季作品继续显示正确季号。
5. 网盘海报卡支持隐藏单个视频版本，隐藏记录在重启和重新扫描后保留，并可逐个或全部恢复；隐藏只影响海报墙，不会删除网盘文件或播放信息。
6. 改进退出时的播放器资源、网盘分段缓存和诊断日志清理；字幕目录改为异步读取，百度请求补齐连接超时和明确失败反馈。
7. 修复只有 TrueHD 音轨的视频能够识别音轨却没有声音，以及蓝光 PGS 内嵌字幕能够识别字幕轨却无法显示的问题。
8. 保留 Windows 硬件解码、4K 零拷贝渲染和 Anime4K 行为；没有 TMDB Key、断网或 TMDB 暂时不可用时，本地与网盘媒体库及播放器仍可使用。本次更新不会修改、删除或转码原始视频和字幕文件。

版本历史只新增一个权威的 `1.0.2` 条目，保留 `2.1.56–2.1.65` 测试版历史和已有 `1.0.1` 正式版记录。

## 修改范围

本次不新增业务行为，只将已经通过本地测试版验证的当前代码整理为正式版。发布元数据修改范围：

- `pubspec.yaml`
- `lib/core/app_version.dart`
- `README.md`
- `RELEASE_NOTES.md`
- `UPDATE_DIALOG_COPY.md`
- `lib/utils/version_history.dart`
- 当前版本与更新弹窗相关测试

测试必须验证 `1.0.2+10002`、`1.0.2.0`、正式版语义、唯一当前版本记录以及上述用户功能关键词一致。

## 构建与本地交付物

使用 `tool/windows/build_signed_release.ps1` 完成 Windows Release、MSIX 封装、签名验证和桌面交付。最终本地文件：

- `看影音-1.0.2.msix`
- `看影音-1.0.2-异机安装包.zip`

必须确认 `kanyingyin.exe` 和 `data/app.so` 为本轮构建产物；MSIX 身份为 `com.kanyingyin.player`，清单版本为 `1.0.2.0`，发布者为 `CN=KanYingYin`，签名有效。桌面 MSIX 与构建产物 SHA-256 必须一致；异机安装 ZIP 内部 MSIX、`SHA256.txt` 和桌面 MSIX 摘要必须一致。

## GitHub Release

最终提交推送到 `main` 后创建并推送标签 `v1.0.2`。先创建草稿 Release，上传并校验附件，再发布并设为 Latest。GitHub 附件名：

- `KanYingYin-1.0.2.msix`
- `KanYingYin-1.0.2-cross-device-installer.zip`

Release 描述使用与更新弹窗一致的八条摘要，并增加下载说明：一般安装下载 MSIX；新电脑提示证书不受信任时下载异机安装 ZIP，完整解压后按“安装说明.txt”操作。描述不得宣称公共在线影视搜索、在线评论或其他不属于项目定位的能力。

## 验证与失败处理

依次执行：

1. 当前版本目标测试。
2. 全量 `flutter test --no-pub`。
3. `flutter analyze --no-pub`。
4. Windows Release 与签名打包脚本。
5. 清单、身份、签名、构建时间、文件清单和 SHA-256 独立验证。
6. Git 状态和关键差异检查，只提交本轮发布文件。
7. 推送 `main` 与 `v1.0.2` 标签。
8. GitHub 草稿 Release 附件摘要验证，验证通过后正式发布。
9. 从公共 GitHub API 重新核对 Latest、描述、附件数量、大小和摘要。

任一测试、构建或本地校验失败时，不创建标签和 Release。GitHub 附件未全部上传并验证前不发布草稿；现有 `v1.0.1` Release 始终保留。
