# Android 诊断日志分享设计

## 背景

Android 播放 TrueHD 音轨失败时，应用会记录播放器底层日志并自动切换兼容音轨。现有 `DiagnosticLogExporter` 已能把诊断摘要和轮转日志打包为脱敏 ZIP，但系统下载目录不可用时会回退到应用私有文档目录，用户无法方便地取得或发送文件。错误日志页面目前只提供复制和清空操作。

## 目标

- 在错误日志页面提供“导出诊断日志”入口。
- Android 生成 ZIP 后直接打开系统分享面板。
- 导出完整脱敏日志，不受页面搜索、等级筛选或增量显示限制。
- 页面没有可解析事件或读取展示失败时，仍允许导出底层日志文件。
- 导出不会清空、移动或修改原日志。

## 非目标

- 本次不修复 TrueHD 解码器本身。
- 本次不改变日志保留数量、轮转策略或日志等级。
- 本次不加入自动上传、遥测或后台发送。
- 本次不改变 Windows 设置页现有的下载目录导出行为。

## 方案选择

采用成熟的 Flutter 系统分享插件。应用先在缓存目录生成诊断 ZIP，再把文件交给 Android 系统分享面板。相比自行维护 `MethodChannel`、`FileProvider` 和 URI 权限，该方案代码更少，也能复用插件对 Android 分区存储和临时文件授权的处理。

不采用固定写入下载目录，因为它不能满足直接发送日志的主要场景，并会引入不同 Android 版本的存储权限和目录可见性差异。

## 组件边界

### 诊断包生成

继续由 `DiagnosticLogExporter` 负责：

- 等待当前日志写入队列刷新。
- 生成包含应用版本、系统版本、处理器架构、硬件解码设置和生成时间的 `diagnostic.txt`。
- 读取当前及轮转日志文件。
- 对摘要和每个日志文件再次执行脱敏。
- 生成带时间戳的 `看影音-诊断日志-YYYYMMDD-HHMMSS.zip`。

Android 分享使用应用缓存目录作为临时输出位置，不把应用私有路径展示给用户。

### 系统分享

新增独立的诊断日志分享服务，职责仅包括：

- 请求 `DiagnosticLogExporter` 在临时目录生成 ZIP。
- 以 ZIP 文件和简短中文说明调用系统分享面板。
- 区分分享成功、用户取消和调用失败。

该服务不读取日志正文，也不绕过现有脱敏流程。错误日志页面通过可注入的回调调用服务，以便组件测试不打开真实系统面板。

### 错误日志页面

在页面顶部操作区加入熟悉的分享图标按钮，工具提示和无障碍名称均为“导出诊断日志”。按钮在以下页面状态都可用：

- 正常显示日志。
- 暂无日志事件。
- 日志展示读取失败。

点击后按钮进入忙碌状态并阻止重复操作。生成完成后打开系统分享面板；用户取消分享时不显示错误。生成或分享失败时显示“导出诊断日志失败，请稍后重试”。

原有“复制全部”“清空日志”和单条复制行为保持不变。

## 数据流

1. 用户在错误日志页面点击“导出诊断日志”。
2. 页面进入导出中状态。
3. 分享服务请求导出器刷新日志并生成脱敏 ZIP。
4. 分享服务把 ZIP 交给 Android 系统分享面板。
5. 用户选择目标应用、保存到文件或取消。
6. 页面结束导出中状态；仅真实失败显示提示。

## 隐私与安全

- ZIP 只包含现有诊断摘要和经过 `LogSanitizer` 处理的日志。
- 不记录或导出网盘账号、密码、Cookie、Token、请求头和远程媒体完整地址。
- 不自动发送文件，必须由用户在系统分享面板中明确选择目标。
- 不申请广泛存储权限。
- 临时 ZIP 留在应用缓存目录，由系统或后续清理流程回收；原日志继续按现有规则轮转。

## 错误处理

- 日志目录不可用、ZIP 写入失败或分享插件调用失败：恢复按钮状态并显示失败提示。
- 用户关闭系统分享面板：视为取消，不显示失败提示。
- 页面在异步操作期间销毁：不再更新页面状态或显示提示。
- 连续点击：导出进行中时忽略后续点击，避免重复生成多个 ZIP。

## 测试与验收

- 单元测试验证诊断 ZIP 包含摘要和轮转日志、保持脱敏且不删除原日志。
- 单元测试验证 Android 临时导出目录和文件名符合约定。
- 组件测试验证正常、空状态和读取失败状态均存在导出入口。
- 组件测试验证点击只触发一次分享，导出期间不能重复触发。
- 组件测试验证用户取消不显示失败提示，真实异常显示失败提示。
- `flutter test` 通过。
- `flutter analyze` 无错误。
- Android Release APK/AAB 构建通过并完成签名、版本及包标识验证。
- Android 实机点击导出后能打开系统分享面板，并能将 ZIP 保存或发送到其他应用。
