# 网盘标签筛选与媒体库边界设计

## 目标

在 Windows 版“网盘媒体库”中为当前选中的网盘来源增加 TMDB 类型标签筛选，同时恢复清晰的媒体库边界：本地媒体库只显示本地资源，网盘资源只显示在网盘媒体库。

## 范围

- 本地媒体库移除网盘作品展示和网盘来源筛选入口。
- 本地媒体库的类型标签仅来自本地媒体的 TMDB 元数据。
- 网盘媒体库在当前网盘名称右侧增加标签筛选入口。
- 网盘标签仅来自当前选中来源的索引项 `tmdbGenres`。
- 标签支持多选，多个标签按任一匹配（OR）处理。
- 标签筛选与现有搜索词、目录范围同时生效（AND）。
- 切换网盘来源时清空已选标签。
- 不删除或迁移任何本地、网盘索引、刮削数据和原始媒体文件。
- 本轮只执行 Windows 和共享 Dart/Flutter 验收，不执行安卓专属测试、构建或安装。

## 界面设计

### 本地媒体库

- 顶部移除“全部”媒体来源菜单及网盘来源选项。
- 保留搜索、排序和 TMDB 类型筛选。
- 类型入口仅列出当前本地媒体库实际存在的标签。
- 列表和计数均只反映本地媒体，不显示云朵图标、网盘名称或网盘作品。

### 网盘媒体库

- 标签入口放在顶部网盘来源下拉框右侧。
- 使用熟悉的标签图标和悬停提示“筛选 TMDB 类型”。
- 菜单使用勾选项显示当前来源可用标签，并提供“清除”命令。
- 已选择标签时在入口显示选择数量；未选择时保持紧凑图标状态。
- 当前来源没有任何 TMDB 标签时，入口保持可识别但不可操作，避免布局跳动。

## 数据流

### 本地媒体库

本地页面直接以 `LocalController.localLibrarySeries` 为唯一作品来源。类型标签从本地系列各分集的 `TmdbMetadata.genres` 聚合，随后依次应用类型、搜索和排序。`combinedMediaLibrary` 中的网盘数据不再参与本地页面的列表、计数或标签计算。

### 网盘媒体库

`CloudResourcesController` 持有当前来源的标签选择状态。可用标签从当前来源已加载的 `CloudMediaIndexItem.tmdbGenres` 去重排序得到。在作品分组前先按标签过滤索引项，确保电影、季度、多版本和作品级分组使用同一筛选结果。

筛选规则：

1. 未选标签时保留全部资源。
2. 选中多个标签时，资源命中任一标签即保留。
3. 没有标签的资源在启用标签筛选时不显示。
4. 搜索词、目录范围和标签条件之间为 AND。
5. 切换来源时清空标签，再加载新来源可用标签。

## 状态与异常

- TMDB 不可用、没有 API Key 或断网时，已有标签仍可筛选；没有标签的资源仍可在未启用筛选时正常浏览和播放。
- 扫描或刮削更新索引后，可用标签随控制器通知刷新。
- 当前已选标签因索引更新而消失时，从选择集合中移除，不产生空白死锁状态。
- 筛选只影响可见作品集合，不修改远程文件、本地文件、索引身份或刮削记录。

## 测试与验收

- 控制器测试：当前来源标签去重排序、多选 OR、与搜索及目录范围组合、切换来源清空、失效标签移除。
- 本地媒体库组件测试：网盘作品和网盘来源入口不出现，本地类型筛选仍生效。
- 网盘页面组件测试：标签入口紧邻来源选择器，菜单可多选和清除，结果只影响当前来源。
- 回归测试：现有网盘扫描、刮削、隐藏、播放和本地媒体库测试通过。
- `flutter analyze --no-pub` 无问题。
- Windows x64 Release 构建和签名 MSIX 生成通过，清单版本、签名和桌面文件哈希验证通过。
- 不运行安卓专属测试，不生成 APK 或 AAB。
