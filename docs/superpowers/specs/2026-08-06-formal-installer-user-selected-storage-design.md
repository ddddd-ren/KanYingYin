# 正式版安装目录与存储目录自选设计

## 目标

正式版 Windows EXE 安装器和应用数据初始化不再依赖 D 盘；用户可以在安装向导中选择安装目录，并在应用设置中选择数据与缓存目录。

## 约束

- Windows 正式版使用 Inno Setup EXE，不生成 MSIX。
- 安装器必须保留目录选择页。
- 没有 D 盘时不能失败，也不能把 D 盘路径写入默认配置。
- 迁移失败时继续使用上一次成功目录，不删除原目录或用户原始媒体。
- Android 不使用 Windows 安装目录逻辑，Android 弹窗不描述 Windows 路径。

## 设计

### Windows 安装器

Inno Setup 的初始目录统一使用 `{localappdata}\\Programs\\看影音`，并保留目录选择页。正式版文案不再把 `D:\\看影音` 作为默认安装位置；用户可以选择任何可用盘符和目录。

### 应用数据与缓存

Windows 首次启动默认使用当前用户可写的应用支持目录和应用缓存目录。用户可以在“设置 > 存储”中分别选择数据目录与缓存目录。已有配置继续优先使用用户保存的目录；迁移请求失败时恢复上一次成功目录并保留原目录。

### 测试兼容

旧配置中已经保存的 D 盘数据路径继续允许读取和迁移，但新版本的安装器、首次启动逻辑、更新弹窗和发布说明不再把 D 盘作为默认条件。

## 验收

- Inno Setup 脚本默认目录不含 `D:\\看影音`，仍声明目录选择页。
- 存储解析器的首次默认目录不含固定 D 盘路径；迁移失败测试保持原目录。
- 发布文案说明安装目录和数据/缓存目录均可自选。
- `flutter test --no-pub`、`flutter analyze --no-pub` 和 Windows EXE 构建通过。
