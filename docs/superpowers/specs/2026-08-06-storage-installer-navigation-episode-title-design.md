# 存储迁移、D 盘安装器、导航与剧集名称设计

## 1. 背景与目标

看影音当前通过 MSIX 安装，程序位于 Windows 管理的 `C:\Program Files\WindowsApps` 目录，用户不能在 MSIX 安装界面指定普通安装目录。本轮新增仅当前用户使用的 Inno Setup EXE 安装器，默认安装到 `D:\看影音`，并允许用户选择其他目录。

本轮同时解决四类问题：

1. 将现有应用数据和可重建缓存迁移到 D 盘，避免安装到 D 盘后设置、媒体库和刮削结果丢失。
2. 在“本次刮削选项”中增加逐集名称开关，统一本地视频和网盘资源的剧名、季集编号和 TMDB 集名显示。
3. 增加可配置的应用数据目录和缓存目录，并提供可恢复的迁移流程。
4. 统一用户界面名称和侧边栏底部工具条布局。

当前安装的 `2.1.134.0` MSIX 不在本轮自动迁移或卸载。下一测试版安装 EXE 成功并验证后，安装器由用户确认是否卸载旧 MSIX。

## 2. 已确认的用户决策

- EXE 采用仅当前用户安装，不要求管理员权限。
- EXE 默认安装到 `D:\看影音`，用户可以在安装界面选择其他目录。
- MSIX 继续保留为独立分发格式。
- EXE 安装成功后，安装器检测现有 `com.kanyingyin.player` MSIX，并由用户确认是否卸载；不自动删除旧版本。
- 现有应用数据和缓存默认迁移到：
  - `D:\看影音\数据`
  - `D:\看影音\缓存`
- 迁移使用临时目录、校验、启动验证和回滚，不删除原始数据直到用户确认。
- `刮削剧集名称`默认开启，只影响本次刮削。
- 侧边栏中“设置”和深色模式按钮并排放在底部工具条。
- “本地媒体库”改为“媒体库”，“播放器设置”改为“设置”。
- 不修改视频文件、本地字幕原文件、网盘远程文件、远程 ID、路径或字幕关联。

## 3. 当前数据边界

当前 Windows 运行环境中，应用支持数据位于系统用户目录下的 `com.kanyingyin\看影音` 命名空间，缓存位于本地应用数据命名空间。实际迁移不得依赖 MSIX 安装目录，因为该目录由 Windows 管理且版本目录会变化。

### 3.1 迁移到 D 盘的普通数据

以下数据迁移到 `D:\看影音\数据`：

- Hive 设置、媒体库索引、观看历史、刮削记录和手动匹配记录。
- 应用日志、WebView 会话、插件资料和 Anime4K 资源。
- 应用生成的其他可重建或可验证资料。

以下缓存迁移到 `D:\看影音\缓存`：

- 网盘海报。
- 网盘字幕缓存。
- 网盘播放范围中转缓存。
- 图片和刮削资料临时缓存。

### 3.2 不迁移的数据

- 本地视频、网盘远程视频和远程目录。
- 视频旁的本地字幕原文件。
- 媒体目录旁的 `.kanyingyin_thumbs` 缩略图；它必须继续跟随媒体目录。
- 账号 Token、TMDB Key 和其他凭据的明文或解密内容。

WebView 会话文件可能包含 Cookie，只作为不透明字节迁移，不读取、不解析、不写入日志。迁移校验失败时删除目标会话副本并要求用户重新登录，不能把会话内容导出为普通账号数据。

`flutter_secure_storage_windows` 继续使用 Windows 当前用户的加密存储。迁移流程不直接复制或解密凭据文件；新 EXE 必须保持相同的应用凭据命名空间，并通过实际读取验证凭据是否可用。若安全存储无法迁移，保留旧安全存储并要求用户重新登录，不得为了迁移而降低保护级别。

## 4. 运行时存储架构

新增统一的存储路径解析层，避免业务服务继续各自调用 `path_provider`：

### 4.1 `StoragePathResolver`

负责在 Hive 初始化前解析：

- 应用数据根目录。
- 缓存根目录。
- 日志、WebView、插件、海报、字幕、播放中转和图片缓存子目录。

路径选择配置保存在独立的启动配置中，不能放在待迁移的 Hive 目录内。配置包含路径版本、数据目录、缓存目录、迁移状态和上一次成功路径。路径解析失败时使用旧路径或系统默认路径，并显示可恢复错误。

### 4.2 `AppDataMigrationService`

负责迁移、校验和回滚：

1. 阻止应用并发启动迁移，关闭 Hive 和播放器相关文件句柄。
2. 检查目标驱动器、目录权限和可用空间。
3. 将源目录复制到目标临时目录，保留相对路径、文件大小和时间戳。
4. 对 Hive 文件、配置文件和迁移清单执行数量、大小及必要的 SHA-256 校验。
5. 写入完成标记后，将临时目录切换为正式目录。
6. 更新启动配置并重启或继续启动应用。
7. 首次启动验证 Hive、媒体库、网盘会话、TMDB 资料和缓存读取。
8. 任一步骤失败时恢复旧路径，保留临时目录供诊断，不删除源目录。

迁移成功后，旧 C 盘目录保留为备份。清理旧备份必须是设置页中的显式操作，不得由安装器静默删除。

## 5. EXE 安装器设计

### 5.1 技术选择

使用 Inno Setup 生成 EXE。项目保存安装器脚本、版本变量、默认目录和校验逻辑；构建环境必须预检 `ISCC.exe`，缺少编译器时构建失败，不能生成未验证的伪安装包。NSIS 和自解压 PowerShell 不作为正式交付方案。

### 5.2 安装流程

- `PrivilegesRequired=lowest`，仅当前用户安装。
- 默认目录为 `D:\看影音`；D 盘不存在或不可写时回退到当前用户可写目录，并在界面中明确显示。
- 安装界面提供目录浏览、空间检查和最终路径确认。
- 写入 EXE、运行库、开始菜单快捷方式和卸载入口。
- 桌面快捷方式遵循应用首次启动询问逻辑，不静默创建。
- 安装前检测 `com.kanyingyin.player`，显示当前 MSIX 版本和路径。
- 安装完成后启动 EXE 做最小验证，再显示是否卸载旧 MSIX 的确认项。
- 旧 MSIX 卸载失败不影响 EXE 使用，并保留错误信息和回滚入口。

MSIX 仍由现有签名流程生成和验证。EXE 另外验证文件版本、安装目录、卸载入口、快捷方式目标、SHA-256 和 Authenticode 签名；如果签名证书不具备代码签名用途，必须明确记录未签名状态，不得将 MSIX 证书状态误报为 EXE 签名成功。

## 6. 剧集名称刮削设计

### 6.1 刮削选项

在本地和网盘共用的“本次刮削选项”中增加 `刮削剧集名称` 开关，默认值为 `true`。选项进入 `TmdbScrapeOptions` 的版本兼容 JSON，缺少字段的旧配置按开启处理。

### 6.2 合并规则

- 开启时，TMDB 成功返回的集名覆盖旧集名，即使旧集名来自错误作品或旧匹配。
- TMDB 详情成功但集名为空时清除旧集名，避免显示错误缓存。
- TMDB 详情请求失败时保留已有元数据，应用仍可播放并显示季集编号。
- 关闭时不显示旧集名；对本次处理的季集记录清除集名展示字段，确保关闭后不会继续出现旧的“死而复生”或其他错误名称。
- 作品自定义标题只控制作品标题和展示前缀，不改变 TMDB 集名字段。

### 6.3 展示格式

本地视频和网盘资源统一通过剧集标题解析器生成展示标题：

```text
作品自定义标题 S01E01 TMDB 集名
```

例如：

```text
回魂计 S01E01 死而复生
```

关闭逐集名称时：

```text
回魂计 S01E01
```

展示层必须使用记录的有效作品标题，而不能重新读取旧 `metadata.title` 作为前缀。该逻辑不改文件名、播放 ID、远程路径或字幕匹配键。

## 7. 设置页与导航

“设置”页面新增“存储”分组：

- 应用数据目录：显示当前路径，允许选择新目录并迁移普通数据。
- 缓存目录：显示当前路径，允许选择、迁移和清理可重建缓存。
- 显示占用空间、迁移状态和重启提示；长路径省略显示，支持复制完整路径。
- 路径切换采用确认对话框，默认执行迁移；用户取消时保持旧路径。
- 清理缓存只删除缓存目录，不删除媒体文件、索引、观看历史或刮削记录。

侧边栏底部工具条包含并排的“设置”和深色模式图标按钮。深色模式按钮使用现有图标体系并提供悬停提示，保持侧边栏宽度和其他动画行为不变。

## 8. 错误处理与离线行为

- D 盘不可用时回退到上一次成功路径，并提示用户修复路径或重新选择目录。
- 没有 TMDB Key、断网、限流和详情失败时，扫描、媒体库浏览、已保存资料查看和播放继续可用。
- 逐集详情缺失时回退到 `SxxExx` 和原始文件名，不阻塞整个批量任务。
- 迁移日志只记录阶段、结果、脱敏错误类型和文件统计，不记录 Token、Cookie、TMDB Key、视频完整路径或网盘凭据。
- 任何迁移和安装失败不得删除原始媒体或旧应用数据。

## 9. 测试与验收

### 9.1 单元和组件测试

- 路径配置读写、默认路径、非法路径和旧配置兼容。
- 数据迁移成功、目标不可写、空间不足、锁文件存在、中途中断和回滚。
- 缓存迁移和清理不影响媒体索引、视频和字幕原文件。
- `刮削剧集名称` 默认值、JSON 兼容、开启覆盖、关闭隐藏旧集名。
- 自定义剧名、TMDB 集名、`SxxExx` 和缺失详情的组合显示。
- 本地视频和网盘资源共用标题解析器。
- 设置页中文名称和侧边栏底部工具条布局。

### 9.2 发布验证

- 查询并记录发布前已安装的 `com.kanyingyin.player` 版本。
- 更新到测试版本 `2.1.135`，MSIX 版本 `2.1.135.0`，同步 `RELEASE_NOTES.md`、`lib/utils/version_history.dart` 及版本契约测试。
- 通过完整 `flutter test`、`flutter analyze` 和 Windows Release 构建。
- 生成签名 MSIX，验证身份、版本、x64 架构、签名和 SHA-256，并复制到桌面。
- 生成 Inno Setup EXE，验证默认 D 盘目录、目录选择、数据迁移、回滚、卸载入口和旧 MSIX 检测。
- 不自动安装或卸载当前版本；若用户后续要求安装，则再次核对实际安装路径、应用启动、媒体库、TMDB 剧集名称和已安装版本。

## 10. 非目标

- 不把 MSIX 的 WindowsApps 目录改造成普通可选目录。
- 不修改原始视频、字幕和网盘远程文件。
- 不将账号凭据复制为普通明文文件。
- 不删除旧版本、旧数据或旧缓存，除非用户明确确认清理。
- 不引入公共在线影视搜索、插件规则或 WebView 视频解析功能。
