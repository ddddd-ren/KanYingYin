# TV 配置配对与加密迁移设计

## 目标

完善看影音 Android TV 配置体验，解决以下实机问题：

- 设置页遥控器焦点不明显，无法确认“测试 TMDB 连接”等操作当前是否选中。
- 手机扫码打开配置页后，电视仍显示“等待手机连接”。
- 手机配置页只有 TMDB 输入，网盘“添加来源”没有形成可用配置界面。
- 手机发送后缺少明确的等待确认和成功反馈。
- 当前没有可在设备之间迁移 TMDB Key 与个人网盘来源、凭据的本机配置文件。

本期只迁移 TMDB API Key、个人网盘来源与网盘凭据。播放器、界面、本地媒体目录、缓存目录、媒体索引、海报缓存和播放历史均不在范围内。

## 已确认决策

- TV 焦点样式采用高对比方案：3 px 主色边框、浅色背景、勾选图标和“当前选中”辅助文字。
- 配置文件包含 TMDB Key 和全部网盘凭据，但必须使用用户密码加密。
- 导入按来源 ID 合并：同 ID 更新，未包含的其他来源保留，不创建重复来源。
- 手机发送后必须由电视端使用遥控器确认，确认前不得写入。
- 手机端和电视端都必须显示连接、等待确认、写入中、成功或失败状态。
- 本期不导出播放器、界面、本地目录或其他普通设置。

## 总体架构

扫码配置和本机文件迁移共用一个 `PortableAppConfiguration` 配置模型、同一套字段校验和同一个原子写入服务。

扫码路径：

1. 电视启动五分钟局域网配对会话并显示二维码。
2. 手机打开二维码地址，服务器通知控制器手机已连接。
3. 电视隐藏主二维码并显示“手机已连接，等待填写配置”。
4. 手机填写 TMDB 和网盘来源，提交后显示“等待电视确认”。
5. 电视显示不含秘密的导入摘要，由用户选择拒绝或确认写入。
6. 确认后配置服务原子写入 TMDB 和网盘配置。
7. 手机收到明确成功响应并切换为只读成功页，电视显示成功页，配对服务器停止接受新请求。

文件路径：

1. 当前设备构建 `PortableAppConfiguration`。
2. 用户输入并确认导出密码。
3. 配置编码、加密后写入 `.kyyconfig`。
4. 目标设备选择文件并输入密码。
5. 应用先解密、校验并展示摘要。
6. 用户确认后调用与扫码路径相同的原子写入服务。

## 配置模型

`PortableAppConfiguration` 包含：

- `formatVersion`：配置明文结构版本，初始为 1。
- `exportedAt`：UTC 导出时间。
- `appVersion`：导出设备的看影音版本。
- `tmdbApiKey`：用户当前保存的 TMDB Key，可为空。
- `cloudSources`：网盘来源与对应凭据列表。

每条网盘记录包含：

- 强类型 `CloudSource`：来源 ID、类型、名称、服务地址、根目录引用、默认转存目录、启用状态和 OpenList 自签名证书选项。
- 可空 `CloudCredential`：用户名、密码、Cookie、Token、客户端 ID/Secret、Access Token、Refresh Token、到期时间、设备 ID 和现有授权关联字段。

导出时清除 `lastScannedAt`、扫描状态、视频数、字幕数和失败数。扫描索引与统计属于设备本地状态，导入后由目标设备重新扫描。

所有模型的 `toString()` 只能输出类型、来源 ID、数量和是否存在凭据，不得输出 Key、密码、Cookie 或 Token。

## 加密文件格式

扩展名为 `.kyyconfig`，最大 512 KiB。文件是 UTF-8 JSON 加密信封：

```json
{
  "format": "kyy-config",
  "envelopeVersion": 1,
  "kdf": {
    "name": "pbkdf2-hmac-sha256",
    "iterations": 600000,
    "salt": "base64"
  },
  "cipher": {
    "name": "aes-256-gcm",
    "nonce": "base64",
    "ciphertext": "base64",
    "mac": "base64"
  }
}
```

- Salt 为 16 个随机字节，Nonce 为 12 个随机字节。
- PBKDF2-HMAC-SHA256 派生 256 位密钥，初始迭代次数为 600000。
- AES-256-GCM 同时提供机密性和完整性校验。
- 明文配置只在内存中存在，不写入临时文件。
- 密码至少 8 个字符，应用不保存、同步或提供找回功能。
- 密码错误、认证标签错误、字段非法、超大文件和不支持的版本统一在写入前失败。
- 错误日志只记录稳定错误类型，不记录文件内容、密码、密钥或凭据。

## 原子合并与回滚

配置写入服务接收已经校验的 `PortableAppConfiguration`，执行以下步骤：

1. 读取当前 TMDB Key、全部来源和本次涉及来源的凭据快照。
2. 按来源 ID 合并来源；同 ID 使用导入值，其他现有来源保留。
3. 保存导入的 TMDB Key。空 Key 表示保持目标设备现有值，不清除现有 Key。
4. 写入每条导入来源的完整凭据。
5. 保存合并后的来源列表。
6. 任一步失败时恢复 TMDB Key、来源列表和所有受影响凭据。

导入结果返回新增来源数、更新来源数、TMDB 是否更新。刷新网盘设置页时必须重新读取仓库，不复用旧控制器快照。

## 手机配置页

手机页面继续由 TV 本地 HTTP 服务提供，不依赖云服务器。页面使用原生 HTML、CSS 和 JavaScript，禁止外部脚本、外部样式和第三方请求。

页面结构：

- 顶部显示连接状态和会话剩余时间。
- TMDB 区提供隐藏输入框。
- 网盘区显示已添加来源卡片和“添加网盘来源”按钮。
- 点击添加后立即插入卡片、滚动到卡片并聚焦类型选择，不使用弹窗或 `<template>` 克隆作为唯一交互路径。
- 来源 ID 在创建卡片时生成一次，编辑和重复构建提交摘要时保持不变。
- 每张来源卡可编辑、删除；提交摘要只显示来源类型和数量。

来源字段：

- OpenList：名称、服务地址、根目录、用户名、密码、自签名证书开关。
- 夸克：名称和 Cookie，服务地址固定为 `https://pan.quark.cn`。
- 百度：名称、客户端 ID、客户端 Secret、Access Token、Refresh Token 和到期时间，服务地址固定为 `https://pan.baidu.com`。
- 迅雷：名称和 Refresh Token，服务地址固定为 `https://pan.xunlei.com`。

百度 OAuth、迅雷账号密码登录和设备验证仍保留在电视原生配置页。手机临时页面只接受已有凭据，不在页面中复刻 OAuth 回调或设备验证流程。

加密配置文件会保留夸克、百度和迅雷已经选择的 `rootRefs`，导入后可直接使用。手机手动新建这三类来源时不允许手写无法验证的目录 ID，而是先保存账号凭据，并在电视成功页标记“需要选择媒体目录”；用户随后进入电视原生来源编辑页选择目录。OpenList 使用路径作为稳定引用，可以在手机页面直接填写根目录。

手机端在提交前按来源类型检查必填字段和 URL。校验失败时定位到对应卡片并显示具体错误；不向电视发送半完成配置。

## 配对状态与反馈

控制器状态扩展为：

```text
idle -> starting -> active -> phoneConnected
     -> awaitingConfirmation -> applying -> success
     -> error
```

- 有效令牌首次打开 `/pair` 时触发幂等的 `onPhoneConnected` 回调。
- `phoneConnected` 状态显示大号手机图标、连接成功文案和等待填写状态，不继续把主视觉停留在二维码。
- 手机提交后，当前 POST 保持等待电视决策，并显示“等待电视确认”。
- 电视拒绝返回 `rejected_on_tv`，手机显示明确拒绝状态并允许修改后重发。
- 电视确认且写入完成后返回 `paired`，手机切换为不可编辑成功页。若手机手动新增的夸克、百度或迅雷来源尚未选择目录，电视成功页提供“前往选择目录”入口。
- 写入失败返回稳定错误状态，手机显示“电视写入失败”，电视显示重试入口。
- 会话超时、取消或应用进入后台会清除待确认配置并停止监听。
- 同一令牌并发提交最多接受一次，成功后令牌立即消费。

配对仍使用同一可信局域网、五分钟一次性高熵令牌、禁止缓存、CSP、电视确认和成功后立即关闭服务。页面明确提示不要在公共 Wi-Fi 使用。二维码和日志不包含任何 TMDB Key、密码、Cookie 或 Token。

## TV 焦点表现

新增可复用的 TV 设置焦点表面，应用到设置页的可操作项，至少覆盖：

- `KSettingsNavigationTile`
- `KSettingsSwitchTile`
- `KSettingsRadioTile`
- TMDB 页的测试连接、清理缓存、配置迁移入口和保存按钮
- 网盘页的扫码配置、来源条目、添加来源和配置迁移入口
- 配对确认、成功、失败页面按钮

TV 获得焦点时使用：

- 3 px 主题主色边框
- 高对比浅色背景
- 勾选图标
- “当前选中 · 按确认执行”辅助文字
- 160 ms `easeOut` 动画，与现有 TV 焦点动画一致

Windows 和普通 Android 保留当前悬停、触摸和键盘表现。TV 表面必须阻止内层 `InkWell` 或按钮再次建立独立焦点，避免双焦点和边框不同步。

## 本机迁移页面

入口位于“设置 → 网盘数据源 → 配置迁移”，Windows、普通 Android 和 Android TV 均显示。

导出：

- 展示将导出的 TMDB 状态和各类型来源数量。
- 要求输入两次相同密码。
- Windows 使用保存文件选择器。
- Android 和 TV 优先使用系统文件选择器保存；系统不支持时使用系统分享面板保存加密文件。
- 成功后显示文件名、来源数量和 TMDB 是否包含，不显示凭据值。

导入：

- 只允许选择 `.kyyconfig`。
- 输入密码后仅解密和生成摘要，不立即写入。
- 摘要显示新增、更新、保留来源数量以及 TMDB 是否更新。
- 用户确认后执行原子合并。
- 成功后刷新网盘来源列表并显示准确计数。

## 错误处理

- 无可用局域网地址：电视显示启动失败和手动配置入口。
- 手机无法连接：提示确认同一可信局域网和 AP 隔离状态。
- 手机字段错误：在本地表单阻止提交并定位到来源卡片。
- 电视拒绝：手机保持表单内容，允许修改后重发。
- 配对超时：两端显示会话已过期，必须重新生成二维码。
- 加密文件错误：区分密码/完整性错误、版本不支持、格式错误和文件过大；不泄漏内部异常。
- 配置写入错误：恢复旧配置，电视和本机迁移页显示“配置写入失败，原配置已保留”。
