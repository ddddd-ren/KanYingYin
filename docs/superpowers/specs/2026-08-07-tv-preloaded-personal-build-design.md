# TV 个人预置配置与刮削资料包设计

## 背景与目标

为用户自己的 Android TV/Google TV（包括 Android 底层的海信电视）生成一份个人测试版。安装后，TV 版本自动导入 Windows 导出的配置文件和刮削资料文件，不要求用户再次打开文件选择器或手机扫码。

本方案只用于用户自有设备的测试包，不改变普通 `tvTest` 构建的通用行为，也不适合作为公开发布包。当前输入文件为 Windows 导出的 `.kyyconfig` 和 `.kyymeta`。

## 输入与安全边界

- 构建输入从工作区外读取：配置文件和刮削资料文件不提交 Git。
- `.kyyconfig` 保持 AES-256-GCM 加密格式，构建过程验证扩展名、大小和可用密码后再打包。
- 构建密码通过临时进程参数或环境变量传入，不写入源代码、设计文档、版本记录、构建日志或 Git。
- 由于用户选择自动导入，个人 APK 内会包含可用于解密预置配置的编译时秘密。任何能提取 APK 的人都可能恢复 TMDB Key 和网盘凭据，因此交付物标记为“个人测试版”，不上传公共仓库或公开分发。
- `.kyymeta` 保留为压缩迁移包，运行时复制到应用私有临时目录，导入结束后删除临时副本；原始视频、字幕、索引和缓存不被删除。

## 架构

### 构建侧

新增个人 TV 构建入口，参数包括配置文件路径、刮削资料路径和密码。入口执行以下步骤：

1. 检查两个文件存在、扩展名正确，配置文件不超过现有配置上限，刮削资料不超过 TV 预置上限。
2. 使用现有 `ConfigurationArchiveCodec` 以密码解密配置，仅验证格式和密码，不把解密明文写入磁盘。
3. 计算两个输入文件的 SHA-256，生成仅包含资源路径、文件类型、大小和哈希的预置清单。
4. 将加密配置、刮削资料和清单复制到一次性 Flutter 资源目录，调用 `tvTest` Release 构建，并在构建后清理资源目录。
5. 通过 `aapt`、APK 签名、Leanback、触摸屏非必需、ABI 和 Full libmpv 校验，复制 APK 到桌面。

正常开发构建没有预置清单时不执行自动导入；清单缺失或校验失败时只跳过预置功能，不影响本地扫描和播放。

### TV 运行时

新增预置导入协调器，仅在 Android TV 且检测到预置清单时运行：

1. 读取资源清单并校验资源大小和 SHA-256。
2. 将加密配置复制到应用私有临时目录，使用编译时密码解密并调用现有配置导入服务。
3. 配置导入完成后刷新本地与个人网盘媒体源，再从资源复制 `.kyymeta` 到临时目录，调用现有刮削资料检查和导入服务。
4. 记录预置清单哈希、导入时间、配置结果和刮削资料匹配结果。相同清单不会重复导入；新版本或清单哈希变化时允许再次导入。
5. 无法匹配的本地媒体、缺少媒体根目录或网盘目录的资料保留为“未匹配”结果，不阻断应用启动；用户仍可从现有配置迁移页面重新导入。
6. 成功、部分成功和失败均写入现有诊断日志，界面显示简短状态；失败时不删除用户原始媒体，不覆盖已有有效配置。

## 版本与交付

- 从当前 `2.1.145+20145` 自动递增到 `2.1.146+20146`，同步 `pubspec.yaml`、`AppVersion`、历史记录、更新说明和验收报告。
- 生成 Android `tvTest` APK，并按项目约定同时生成 Windows Release 和 Inno Setup EXE；不生成 MSIX。
- APK 文件名：`看影音-2.1.146-TV个人预置测试版.apk`。
- Windows 安装器文件名：`看影音-2.1.146-测试版-安装程序.exe`。
- 个人 APK 和安装器只复制到当前用户桌面，不上传或提交包含个人资源的构建目录。

## 错误处理

- 输入文件不存在、扩展名错误、超限、密码错误或哈希不一致：构建立即失败并清理临时资源，不生成个人 APK。
- TV 资源读取失败、解密失败或资料包损坏：记录明确原因，跳过对应导入并继续启动；已有配置保持不变。
- 配置导入成功但资料部分未匹配：显示匹配数量、缺失数量和可恢复图片数量，允许后续手动重试。
- 任何异常都不得把密码、TMDB Key、网盘凭据或配置明文写入日志。

## 测试与验收

- 单元测试覆盖预置清单解析、哈希校验、幂等标记、成功/失败/部分匹配状态和临时文件清理。
- TV Widget/契约测试确认没有预置清单时行为与普通 `tvTest` 相同。
- 构建验证确认 APK 版本、包名、签名、Leanback、三种 ABI 和 Full libmpv；Windows 安装器与 Release 主程序产品版本一致。
- 在海信 Android TV 实机上验证首次自动导入、重启不重复导入、错误资源不阻断启动、网盘来源和刮削海报可用。若设备是 VIDAA 原生系统，则记录为不兼容。

## 非目标

- 不把个人配置解密后提交到 Git 或作为公开资源发布。
- 不把 Windows 本地视频文件打进 APK；TV 只能导入可匹配的元数据，视频仍需位于 TV 可访问的本地存储或个人网盘。
- 不改变现有手机扫码配对协议和普通 Android/Windows 版本的导入流程。
