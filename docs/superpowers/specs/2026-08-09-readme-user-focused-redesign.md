# README 用户向精简重构设计

## 背景

仓库首页的版本号已经更新到 Windows 1.0.7 和 Android 1.0.4，但正文仍保留大量测试阶段说明、重复的媒体识别规则和过细的实现细节。新用户难以快速了解产品用途、支持平台、下载方式和数据安全边界。

## 目标

将 `README.md` 重构为面向普通用户的产品首页，同时在后半部分保留开发者需要的构建、项目结构、开源致谢和许可证信息。

首页需要准确反映当前正式发布状态：

- Windows 正式版为 1.0.7，提供 EXE 安装程序。
- Android 手机正式版为 1.0.4，提供 APK；AAB 作为应用商店交付包保留在 Release 中。
- Android TV 正式版、测试版和 GitHub 发布无限期暂停，不提供 TV 下载资产。

## 信息结构

### 1. 顶部产品区

- 保留应用名称和图标。
- 使用一段简短文案说明产品定位：管理和播放用户自己的本地及个人网盘视频。
- 提供 Windows、Android 手机的当前版本和 GitHub Release 下载入口。
- 不展示 Android TV 下载入口。

### 2. 核心功能

按用户任务拆分为以下五组，每组只保留关键能力，不罗列底层识别规则：

- 本地与个人网盘媒体库。
- TMDB 中文元数据与手动匹配。
- Windows 和 Android 播放器能力。
- 字幕、音轨与播放体验。
- 配置迁移、诊断和数据安全。

OpenList、夸克、百度和迅雷统一归入“个人网盘”能力。按用户要求保留“OpenList 功能仍在调试，当前不建议使用”的提醒，同时删除其他重复的测试期说明；仍需保留远程服务变化可能影响兼容性的客观提醒。

### 3. 数据安全边界

集中说明以下承诺，避免在各功能段落反复出现：

- 应用只处理用户自己的媒体。
- 删除来源、索引或缓存不会删除、改名或移动原始文件。
- 没有 TMDB Key、TMDB 不可用或断网时，本地扫描、浏览和播放仍可使用。
- 凭据通过系统安全存储保存，诊断日志会隐藏敏感字段。
- 不包含公共在线影视搜索、视频解析或资源聚合功能。

### 4. 平台、下载与快速开始

- 使用真实 GitHub 资产名：`KanYingYin-1.0.7.exe`、`KanYingYin-1.0.4.apk` 和 `KanYingYin-1.0.4.aab`。
- Windows 和 APK 面向普通用户；AAB 明确标注为应用商店交付包。
- 安装说明链接当前 `v1.0.7` Release。
- Windows 安装目录由用户选择，不要求存在 D 盘。
- 快速开始控制在添加媒体、配置可选 TMDB、选择个人网盘和开始播放几个步骤内。

### 5. 开发者信息

保留并压缩以下内容：

- Flutter 版本与依赖恢复命令。
- 测试、静态分析、Windows Release、Android 签名包和 Inno Setup EXE 构建命令。
- 项目目录结构。
- 开源来源、TMDB 声明和 GPL-3.0 许可证。

播放器组件的详细联合验证流程不再占据首页主体；若必须保留，只保留简短入口或折叠说明。

## 删除与合并范围

- 删除重复出现的安全承诺和网盘只读说明，合并到数据安全章节。
- 删除大量具体文件名、目录名、季度号和发布标签识别示例。
- 保留“OpenList 功能仍在调试，当前不建议使用”的提醒，删除“迅雷为测试能力”等其他旧文案。

- 保留当前正式版已经验证且对用户有直接价值的 HDR、Anime4K、字幕修复、剧集匹配和配置迁移能力，但用概括性语言描述。

- README 顶部可在一屏左右看清产品定位、支持平台和下载入口。
- Windows 1.0.7、Android 1.0.4 和 Android TV 暂停状态准确一致。
- 下载文件名与 GitHub `v1.0.7` Release 的三个资产一致。
- 不包含旧测试状态、过期版本号或 TV 下载入口。
- 不夸大未经验证的能力，不声称 Windows EXE 已签名或 Android 已完成真机验收。
