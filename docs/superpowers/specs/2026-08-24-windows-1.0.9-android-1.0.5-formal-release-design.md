# Windows 1.0.9 与 Android 1.0.5 正式版发布设计

## 当前状态与版本代差

- GitHub 最新正式版为 Windows 1.0.8，Android 正式版为 1.0.4，标签为 `v1.0.8`。
- 本地 Windows 与 Android 源码版本均为测试版 2.1.169。
- Windows 正式版之后累计 2.1.159 至 2.1.169，共 11 个测试版本。
- Android 1.0.4 之后实际构建并交付过 2.1.159 与 2.1.160；当前 Android 源码还包含 2.1.161 至 2.1.169 的共享业务改动。
- 当前已安装 Windows EXE 为 2.1.169，路径为 `D:\看影音\kanyingyin.exe`；未发现旧 MSIX。
- GitHub 远端 `main` 仍停在 v1.0.8 对应提交，本地后续提交尚未推送。

因此，本次 Windows 正式版从 1.0.8 递增为 1.0.9，Android 正式版从 1.0.4 递增为 1.0.5。

## 发布范围

本次发布 Windows 与 Android 手机正式版：

- Windows 应用版本：`1.0.9+10009`
- Windows EXE 安装器版本：`1.0.9`
- Android 手机版本：`1.0.5 (10005)`
- GitHub 标签：`v1.0.9`
- GitHub Release 标题：`看影音 1.0.9 正式版`
- GitHub Release 资产：
  - `KanYingYin-1.0.9.exe`
  - `KanYingYin-1.0.5.apk`
  - `KanYingYin-1.0.5.aab`

Android TV 继续无限期暂停：不得运行 `tvTest`，不得构建、复制或上传 TV 安装包、标签或 Release。历史 MSIX 配置只同步兼容版本，不生成 MSIX。

## Windows 用户弹窗

### 标题

看影音 1.0.9 正式版

### 正文范围

- 网盘播放时在进度条下显示实时网速；控制栏收起时同步隐藏。
- 网盘读取速度不足提示可对当前视频关闭；重新连接或读取失败仍显示必要提示。
- 修复夸克季度目录内以“01 集名”“02 集名”开头的视频漏扫，并支持季度目录中的同名子目录。
- 改善网盘剧集 TMDB 逐集名称映射和手动季度匹配，保存后保持用户确认的季度与集名。
- 作品资料同步暂时失败时仍保留已经保存的手动匹配结果。
- OpenList 使用账号或令牌时要求 HTTPS，匿名 HTTP 连接保持可用。
- 网盘海报优先从本地缓存显示，减少白色空白卡片、占位图闪烁和重复加载。
- Windows 每天从 GitHub 自动检查一次最新正式版，也可在“关于”页面手动检查。
- 应用内下载 Windows 更新时校验安装包大小和 SHA-256，校验失败时不运行文件。
- 本地与个人网盘海报常驻显示作品最高规格；选集、版本和播放器右侧选集显示各文件的分辨率、杜比视界、HDR10+、HDR 和杜比全景声等技术标签。
- 本次更新不会修改、删除、改名或移动本地及个人网盘原始视频和字幕。

Windows 弹窗不写 Android 高刷新率或 Android 设备专项优化。

## Android 用户弹窗

### 正文范围

按用户要求，Android 弹窗不得出现“天玑 930”“vivo Y77”或对应的夸克专项读取优化。Android 弹窗也不得包含 Windows GitHub 自动更新、EXE 安装器或系统代理说明。

## 验证与构建

实施完成后必须验证：

1. 完整 `flutter test --no-pub` 通过。
2. `flutter analyze --no-pub` 无问题。
3. Windows Release 构建成功，`kanyingyin.exe` 产品版本为 1.0.9。
4. Inno Setup EXE 构建成功，安装器产品版本为 1.0.9，并复制到当前用户桌面。
5. Android mobile APK 与 AAB 构建成功，包名为 `com.kanyingyin.player`，versionName 为 1.0.5，versionCode 为 10005。
6. APK 签名、AAB 严格签名及 APK/AAB Full libmpv 三种 ABI 校验通过。
7. 记录 EXE、APK、AAB 的文件大小与 SHA-256；记录 EXE Authenticode 状态和 Android 签名证书摘要。
8. 不运行 Android TV 构建脚本，不生成 MSIX。
9. 不自动安装 Windows 1.0.9；不宣称 Android 已完成真机播放验收。

## GitHub 发布

验证通过后：

1. 将当前本地 `main` 的正式版改动和此前未推送提交一起推送到 GitHub `main`。
2. 创建并推送带注释标签 `v1.0.9`。
3. 创建草稿 Release `看影音 1.0.9 正式版`。
4. 只上传 `KanYingYin-1.0.9.exe`、`KanYingYin-1.0.5.apk` 和 `KanYingYin-1.0.5.aab`。
5. 逐项比较本地与 GitHub 资产名称、大小和 SHA-256，全部一致后再公开 Release 并设为最新版。
6. 最后核对远端 `main`、`v1.0.9`、公开 Release、本地 HEAD 和工作区状态。

## 验收边界

- Windows 正式版综合 2.1.159 至 2.1.169 中适用于 Windows 的功能。
- Android 正式版使用当前完整源码，但弹窗只写 Android 可感知功能和共享业务更新。
- Android 弹窗不写天玑 930、vivo Y77 或夸克专项读取优化。
- Android 弹窗不写 Windows 自动更新功能。
- Android TV 不构建、不发布、不上传。
- 不删除用户原始视频、字幕或远端文件。
- 不把未签名 EXE 描述为已签名，不把包级校验描述为真机验收。
