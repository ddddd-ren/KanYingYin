# 海报封面统一规范与深色白边修复设计

## 背景

《怪奇物语》第 2～5 季的四张缓存海报均为 `500×750`，原图左右各带约 `11～12px` 白框。深色模式最初使用 `1.04` 居中放大后，抗锯齿采样仍会在左右边缘显示白线；`1.06` 可以覆盖这组真实素材的白框。

现有海报入口分别维护尺寸、圆角、图片加载和失败占位，主海报墙、季度选集、播放历史、TMDB 候选和媒体库小图的宽高比也不完全一致。本次修复同时建立一套共享显示规范，避免同类问题在其他入口重复出现。

## 目标

- 深色模式下，《怪奇物语》第 2～5 季海报不再出现左右白线。
- 本地主海报墙、网盘海报墙、分类页、季度选集、播放历史、TMDB 候选和媒体库小图统一使用 `2:3` 封面比例。
- 所有入口统一真实海报的裁边规则，以及无图、加载中和加载失败的占位样式。
- 保留现有标题、评分、技术标签、悬停、焦点、操作菜单和点击行为。
- 保留各入口现有的本地缓存、TMDB 网络和网盘图片加载链路。
- 图片失败只影响封面显示，不阻断本地扫描、媒体库浏览或播放。

## 非目标

- 不扫描海报像素，不按图片内容动态识别边框。
- 不修改、覆盖或重新编码任何海报缓存原文件。
- 不把本地、网络和网盘图片加载合并成新的万能加载器。
- 不调整卡片文字结构、技术标签、悬停动画、菜单或播放逻辑。
- 不修改 Android TV 专用五列布局，不构建或交付 Android TV 产物。
- 本轮只交付 Windows Inno Setup 测试版，不生成 MSIX，也不打包 Android 手机版本。

## 共享封面显示规则

新增一个最小共享封面显示层，职责仅限于真实海报的主题裁边和统一占位；各页面继续负责选择图片来源，父布局继续负责尺寸。

- 固定封面宽高比常量为 `2 / 3`。
- 深色模式下，真实海报使用 `BoxFit.cover`，以中心为原点放大 `1.06`，并在封面边界内裁切。
- 浅色模式下不放大，保持 `1.00`，继续按 `BoxFit.cover` 展示原图。
- 无图、加载中和加载失败统一使用主题的中性表面色与居中的 `Icons.movie_outlined`。
- 占位不使用渐变、彩色圆形装饰或 `broken_image` 图标。
- 圆角由入口外层裁切，真实海报与占位共享同一裁切边界，不出现两层圆角。

共享层不保存图片状态、不发起网络请求、不访问文件系统，也不控制页面布局。`CloudPosterImage` 继续维护现有稳定 State、本地帧保留、缓存优先和网络回退，只把最终图片与占位交给共享显示规则。

## 入口尺寸与圆角

### 主海报墙与分类页

覆盖本地媒体库、个人网盘海报墙和媒体分类页。

- 网格继续按窗口宽度响应式增减列数，卡片最大宽度保持现有约 `300px` 上限。
- Windows 与手机版 Android 的通用网格宽高比由近似 `0.68` 改为精确 `2 / 3`。
- 卡片圆角保持 `12px`。
- 现有整卡遮罩、标题、评分、技术标签、悬停与操作菜单保持不变。
- Android TV 专用 `0.78` 五列策略保持不变，避免把暂停交付的平台带入本次范围。

### 网盘季度选集

- 保持现有 `92×138`，该尺寸已经是 `2:3`。
- 保持 `9px` 圆角。
- 接入统一深色裁边和占位，不改变季度标题、简介、集数和选集列表。

### 播放历史

- 封面由 `72×88` 调整为 `60×90`。
- 保持 `6px` 圆角。
- 标题、来源、集号、播放进度和删除操作保持不变。

### TMDB 候选

- 封面由 `58×82` 调整为 `56×84`。
- 保持 `6px` 圆角。
- 无海报和下载失败都使用统一占位，不再分别显示普通影片图标和损坏图片图标。
- 推荐状态、候选标题、年份、简介和选择行为保持不变。

### 本地媒体库小图

- 封面由 `40×56` 调整为 `40×60`。
- 保持 `4px` 圆角。
- 本地缓存与网络地址的现有回退顺序保持不变。

## 图片数据流与失败回退

每个入口继续沿用当前可用的数据源和回退顺序：

1. 优先显示已经落盘的海报缓存。
2. 缓存缺失或不可用时，使用现有 TMDB 或网盘网络海报地址。
3. 无有效地址、加载中或加载失败时，显示统一中性占位。

主题切换只重新计算显示层的 `1.06` 或 `1.00`，不重新下载图片，不改写缓存，也不改变媒体身份。网络失败、TMDB 无 API Key 或断网时，本地扫描、索引、浏览和播放继续可用。

## 自动化测试

先保留现有真实渲染像素回归，再补齐共享规则和入口契约：

- 深色模式使用带 `12px` 白框的 `500×750` 测试海报，渲染到 `250×375` 后检查左右边缘像素，确保 `1.06` 裁切后不再出现亮色细线。
- 浅色模式验证不应用额外放大，原图边缘按原始构图显示。
- 验证无图、加载中和失败状态使用同一中性占位与 `movie_outlined` 图标。
- 验证主海报墙、网盘海报墙和分类页使用精确 `2 / 3` 的通用网格比例，TV 专用比例保持不变。
- 验证季度选集为 `92×138`、播放历史为 `60×90`、TMDB 候选为 `56×84`、媒体库小图为 `40×60`。
- 验证标题、技术标签、悬停、菜单、播放进度和选择行为的现有测试仍通过。
- 完整执行 `flutter test --no-pub` 与 `flutter analyze --no-pub`。

## Windows 构建与真实验收

自动化测试与静态分析通过后：

1. 构建 Windows Release。
2. 生成 Inno Setup 测试版安装程序，不生成 MSIX。
3. 核对安装器与 Release 目录中的 `kanyingyin.exe` 均为 `2.1.178`。
4. 将安装程序复制到桌面，文件名为 `看影音-2.1.178-测试版-安装程序.exe`。
5. 安装测试版后再次核对已安装 `kanyingyin.exe` 的产品版本。
6. 在深色模式逐一检查《怪奇物语》第 2、3、4、5 季，确认左右无白线。
7. 切换浅色模式，确认海报不使用深色模式的额外放大。
8. 逐一检查本地主海报墙、网盘海报墙、分类页、季度选集、播放历史、TMDB 候选和媒体库小图，确认比例、圆角、占位和原有交互。
