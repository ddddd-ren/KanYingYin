看影音 Windows 安装说明

Windows EXE 安装器：

1. 双击“看影音-版本号-测试版-安装程序.exe”。
2. 安装向导始终显示目录选择页，用户可以自选任意可用盘符和目录；选择的目录就是程序实际安装目录，不要求电脑存在 D 盘。
3. 安装器只为本机当前用户安装，不要求管理员权限，也不会静默创建桌面快捷方式。
4. 应用数据和缓存目录可在“设置 > 存储”中分别选择；迁移失败时保留并继续使用原目录。
5. 安装完成后从开始菜单启动“看影音”。首次启动会按应用提示询问是否创建快捷方式。

公共安装包不内置 TMDB Key。百度网盘使用用户自己填写的百度开放平台 API Key、Secret 和官方授权，应用不会修改百度网盘原文件。

旧版异机证书安装脚本说明：

- 旧版安装脚本需要管理员权限，并只把公开证书导入本机 `Cert:\LocalMachine\TrustedPeople`。
- 不要使用当前用户证书存储，也不要导入 `Cert:\LocalMachine\Root`。
